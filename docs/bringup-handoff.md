## 项目目标

在STM32G431CBU6平台上逐步实现：

1. 基于三路霍尔传感器的六步换相；
2. 霍尔测速；
3. 速度给定斜坡；
4. PI速度闭环；
5. 堵转、非法霍尔和电压等基础保护。

对象为磁悬浮离心泵，没有机械轴，启动特性可能比普通BLDC更敏感。当前坚持低压、限流、低占空比逐步验证。

## 已确认硬件

### 主控与电机

- MCU：STM32G431CBU6
- 系统时钟：168 MHz
- 电机：8极，即4极对
- 电压：12～24 V
- 电流：0～1 A
- 目标转速：0～3000 rpm
- 每机械圈霍尔有效边沿数：`6 × 4 = 24`

### 功率级

- 栅极驱动器：JSM6288T
- MOSFET：HSBB6066，60 V N沟道MOSFET
- JSM6288T输入兼容3.3 V，高电平有效
- JSM6288T具有高低侧互锁、内部死区及欠压保护
- 控制方式：高桥PWM，低桥GPIO
- 板上没有独立驱动使能引脚

### 引脚映射

| 功能 | 引脚 | 配置 |
|---|---|---|
| UH | PA8 | TIM1_CH1 PWM |
| UL | PC13 | GPIO，高电平导通 |
| VH | PA9 | TIM1_CH2 PWM |
| VL | PA12 | GPIO，高电平导通 |
| WH | PA10 | TIM1_CH3 PWM |
| WL | PB15 | GPIO，高电平导通 |
| Hall U/A | PB8 | EXTI，低有效，已转换为3.3 V |
| Hall V/B | PB7 | EXTI，低有效，已转换为3.3 V |
| Hall W/C | PB6 | EXTI，低有效，已转换为3.3 V |
| 按键 | PC10 | 下降沿EXTI，不是驱动使能 |
| 状态灯 | PC6 | GPIO输出 |
| 母线电压 | PA0 | ADC1_IN1，分压比例待确认 |
| U相电流OPAMP+/- | PA1 / PA3 | ADC/OPAMP，尚未启用 |
| V相电流OPAMP+/- | PA7 / PA5 | ADC/OPAMP，尚未启用 |
| W相电流OPAMP+/- | PB0 / PB2 | ADC/OPAMP，尚未启用 |

## 已实现软件

### 安全功率输出层

文件：`Core/Src/motor_pwm.c`、`Core/Inc/motor_pwm.h`

- TIM1采用中心对齐PWM，频率约10 kHz，PWM1模式；
- 只使用CH1、CH2、CH3三路高桥PWM；
- 三个低桥为普通GPIO；
- 上电时所有高低桥命令关闭；
- 每次换相先全部关断，再应用新状态；
- 测试占空比固定5%；
- 软件最大占空比暂时限制为10%。

六种功率状态已经用示波器逐项测试通过：

| Step | 高桥PWM | 低桥导通 | 悬空相 |
|---:|---|---|---|
| 1 | UH | VL | W |
| 2 | UH | WL | V |
| 3 | VH | WL | U |
| 4 | VH | UL | W |
| 5 | WH | UL | V |
| 6 | WH | VL | U |

### J-Link RTT

文件：`Core/Src/rtt_log.c`、`Core/Inc/rtt_log.h`

- 工程内置最小RTT实现，可被J-Link RTT Viewer自动发现；
- 已修复ARMCC下`__DMB`未定义问题；
- 不使用USART输出调试日志。

### 霍尔采集

文件：`Core/Src/hall.c`、`Core/Inc/hall.h`

- PB6～PB8配置为双边沿EXTI；
- 霍尔低有效，软件读取后取反；
- 编码：`hall = (U << 2) | (V << 1) | W`；
- `000`、`111`判为非法；
- 相邻状态变化超过一位判为`JUMP`；
- 霍尔异常时关闭功率输出。

手转正向实测霍尔顺序：

```text
001 -> 011 -> 010 -> 110 -> 100 -> 101 -> 001
```

手转一机械圈得到24个霍尔区间，和4极对一致。未单独进行反转手转测试，理论逆序为：

```text
001 -> 101 -> 100 -> 110 -> 010 -> 011 -> 001
```

### 自动六步换相

文件：`Core/Src/motor_control.c`、`Core/Inc/motor_control.h`

- 上电保持停止；
- PC10按键控制启动/停止；
- 启动时读取当前霍尔状态并立即应用对应换相步骤；
- 运行时由霍尔边沿中断触发换相；
- 固定5%占空比；
- 500 ms无霍尔变化，关断并输出`FAULT Hall timeout`；
- 非法状态或非法跳变，立即关断；
- PC6亮表示运行，灭表示停止。

当前已验证的映射表：

| Hall | 换相状态 |
|---|---|
| 001 | UH + VL |
| 011 | UH + WL |
| 010 | VH + WL |
| 110 | VH + UL |
| 100 | WH + UL |
| 101 | WH + VL |

## 实际联调结果

固定5%占空比启动后，电机已实现稳定连续旋转。RTT日志长期保持如下循环：

```text
RUN duty=5%
H=010 OK
H=110 OK
H=100 OK
H=101 OK
H=001 OK
H=011 OK
```

一次记录中边沿计数从`N=643`连续增加到`N=730`，期间：

- 顺序稳定；
- 没有丢失或重复状态；
- 没有`INV`；
- 没有`JUMP`；
- 没有霍尔超时；
- 当前候选换相表无需平移即可持续运行。

尚未归档的实测数据：母线电压、稳态电流、实际RPM、启动时间、温升、振动和多次启动成功率。

## 下一步计划

下一阶段先实现霍尔测速和低频运行状态输出，不直接上PI：

1. 使用高分辨率时间基准测量相邻霍尔边沿周期；
2. 根据4极对、每圈24边沿计算RPM；
3. 对周期或RPM做合理滤波；
4. RTT改为每100～200 ms输出一次运行状态，不再逐边沿刷屏；
5. 保留非法霍尔和故障即时日志；
6. 分离启动超时与运行堵转判定；
7. 记录启动时间和启动成功状态；
8. 测速稳定后，再加入速度给定斜坡和PI闭环。

理论换算：

```text
RPM = 60 × edge_frequency / 24
RPM = 2,500,000 / edge_period_us
```

首次继续测试前，应先让用户补充或测量：

- 当前母线电压；
- 稳态电源电流；
- 启动是否每次成功；
- 运行声音和振动；
- MOSFET、JSM6288T和电机运行1～2分钟后的温升。

## 安全约束

- 未验证的新代码上电默认必须关闭功率级；
- 功率测试保持低压、限流、电机空载或按泵体要求灌液；
- 映射异常、只抖动、进入限流或异常发热时立即断电；
- 不直接用普通接地示波器探头跨接高边栅源或开关节点；
- 在电流采样与硬件故障输入完成前，电源限流仍是主要过流保护。
