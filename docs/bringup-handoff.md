## 项目目标

在STM32G431CBU6平台上逐步实现：

1. 基于三路霍尔传感器的六步换相；
2. 霍尔测速；
3. 速度给定斜坡；
4. PI速度闭环；
5. 堵转、非法霍尔和电压等基础保护。

对象为磁悬浮离心泵，没有机械轴，启动特性可能比普通BLDC更敏感。当前坚持低压、限流、低占空比逐步验证。

## 已确认硬件

### 主控与电机

- MCU：STM32G431CBU6
- 系统时钟：168 MHz
- 电机：8极，即4极对
- 电压：12～24 V
- 电流：0～1 A
- 目标转速：0～3000 rpm
- 每机械圈霍尔有效边沿数：`6 × 4 = 24`

### 功率级

- 栅极驱动器：JSM6288T
- MOSFET：HSBB6066，60 V N沟道MOSFET
- JSM6288T输入兼容3.3 V，高电平有效
- JSM6288T具有高低侧互锁、内部死区及欠压保护
- 控制方式：高桥PWM，低桥GPIO
- 板上没有独立驱动使能引脚

## 已实现软件

### 安全功率输出层

文件：`Core/Src/motor_pwm.c`、`Core/Inc/motor_pwm.h`

- TIM1采用中心对齐PWM，频率约10 kHz，PWM1模式；
- 只使用CH1、CH2、CH3三路高桥PWM；
- 三个低桥为普通GPIO；
- 上电时所有高低桥命令关闭；
- 每次换相先全部关断，再应用新状态；
- 测试占空比固定5%；
- 软件最大占空比暂时限制为10%。

六种功率状态已经用示波器逐项测试通过：

| Step | 高桥PWM | 低桥导通 | 悬空相 |
|---:|---|---|---|
| 1 | UH | VL | W |
| 2 | UH | WL | V |
| 3 | VH | WL | U |
| 4 | VH | UL | W |
| 5 | WH | UL | V |
| 6 | WH | VL | U |

### J-Link RTT

文件：`Core/Src/rtt_log.c`、`Core/Inc/rtt_log.h`

- 工程内置最小RTT实现，可被J-Link RTT Viewer自动发现；
- 已修复ARMCC下`__DMB`未定义问题；
- 不使用USART输出调试日志。

### 霍尔采集

文件：`Core/Src/hall.c`、`Core/Inc/hall.h`

- PB6～PB8配置为双边沿EXTI；
- 霍尔低有效，软件读取后取反；
- 编码：`hall = (U << 2) | (V << 1) | W`；
- `000`、`111`判为非法；
- 相邻状态变化超过一位判为`JUMP`；
- 霍尔异常时关闭功率输出。

手转正向实测霍尔顺序：

```text
001 -> 011 -> 010 -> 110 -> 100 -> 101 -> 001
```

手转一机械圈得到24个霍尔区间，和4极对一致。未单独进行反转手转测试，理论逆序为：

```text
001 -> 101 -> 100 -> 110 -> 010 -> 011 -> 001
```

### 自动六步换相

文件：`Core/Src/motor_control.c`、`Core/Inc/motor_control.h`

- 上电保持停止；
- PC10按键控制启动/停止；
- 启动时读取当前霍尔状态并立即应用对应换相步骤；
- 运行时由霍尔边沿中断触发换相；
- 固定5%占空比；
- 500 ms无霍尔变化，关断并输出`FAULT Hall timeout`；
- 非法状态或非法跳变，立即关断；
- PC6亮表示运行，灭表示停止。

|---|---|
| 001 | UH + VL |
| 011 | UH + WL |
| 010 | VH + WL |
| 110 | VH + UL |
| 100 | WH + UL |
| 101 | WH + VL |

### 2026-08-13 静止水流占空比阶梯测试补充

静止水流下分别测试5%、6%、8%、10%、20%启动占空比，所有档位启动成功率均为0%。给泵提供流动水流、降低启动阻力后，电机可以旋转起来。

该结果表明启动失败不能仅靠在现有霍尔直接换相逻辑中提高固定占空比解决。20%测试已经超出原软件10%安全上限，后续不要继续提高占空比；在电流采样和硬件故障输入完成前，仍须依靠电源限流。

下一步先区分以下两种情况：

1. 静止水流启动时转子完全不动、霍尔状态不变化：重点检查静止负载/转子支承条件，并测试各初始霍尔位置是否能产生起动动作；
2. 转子会抖动或出现少量霍尔边沿，但不能连续加速：实现受限的启动状态机，采用短时起动占空比和开环六步换相斜坡，检测到连续合法霍尔边沿后再切换至霍尔闭环。

在上述现象确认前，不直接加入速度PI，也不继续提高启动占空比。

### 2026-08-13 5%占空比再次启动成功

恢复5%占空比后，泵随后可以正常启动。RTT记录从`N=4705`到`N=4738`持续按`110 -> 100 -> 101 -> 001 -> 011 -> 010`循环，没有`INV`、`JUMP`或超时。此前静止水流下多档占空比均失败、随后5%又成功，说明启动成功率存在明显的条件依赖和偶发性，不能据此认为启动可靠；后续仍需累计多次冷启动/完全停稳启动数据。

补充电机结构：定子6槽，转子8极（4极对）。霍尔测速仍按每机械圈`6 × 4 = 24`个有效边沿计算。

已进入霍尔测速阶段：使用168 MHz的DWT周期计数器测量相邻合法霍尔边沿周期，按24边沿/机械圈换算RPM，并进行一阶周期滤波；RTT改为每200 ms输出一次`RUN H=xxx RPM=... N=...`，非法霍尔和故障仍即时输出。测试占空比保持5%，软件上限保持10%。

### 2026-08-13 首次霍尔测速结果

5%占空比下完成两次启停测试，两次均成功启动。全部运行日志中霍尔边沿计数持续增加，没有`INV`、`JUMP`或Hall超时，说明换相和霍尔采集仍然可靠。

第一次运行从`N=31`增加到`N=1131`，第二次从`N=1153`增加到`N=1676`。启动阶段RPM从低值逐步上升，符合加速过程。进入运行后，单边沿周期法显示的RPM约在200～389 rpm之间波动；但每200 ms的边沿增量通常约20～29个，对应窗口平均转速约250～363 rpm（`RPM = ΔN × 12.5`）。

当前判断：RPM跳动主要来自单个60电角度霍尔区间长度不均、霍尔安装误差和六步换相转矩脉动。当前一阶边沿周期滤波不足以代表稳定机械转速。下一步应改用固定200 ms窗口内的霍尔边沿增量作为状态输出RPM；单边沿周期仍可保留用于快速堵转检测。完成窗口测速后，再评估是否需要更长窗口或滑动平均，暂不加入速度PI。

补充观察：用户肉眼确认叶轮转速确实忽快忽慢，因此波动不只是单边沿测速噪声。日志中的窗口边沿增量也有明显变化，与实际转速不稳一致。当前5%固定占空比可能处于带水负载下的临界转矩区；此外需排除电源限流/母线跌落、流路气泡或流量变化、叶轮接触或磁悬浮状态不稳，以及特定霍尔区间换相转矩不均。

下一轮先保持开环固定占空比，不加PI，按顺序对比5%、8%、10%已经成功启动后的稳态表现。每档记录约10 s的RTT日志、母线电压最小值、电源电流变化范围、声音振动和肉眼转速波动。若提高占空比后明显稳定，优先判断为5%转矩余量不足；若各档仍周期性忽快忽慢，则继续检查流路/转子机械状态和各霍尔区间周期，不用PI掩盖基础问题。

### 2026-08-13 5%～10%固定占空比对比

完成5%、6%、8%、10%固定占空比运行日志对比。结果不是占空比越高越稳定：5%总体运行时间最长、边沿增长较连续；6%出现多次明显减速；8%同样波动并较早停止；10%最差，末尾`N=432`连续两个200 ms状态周期不再增加，表明转子已经停滞或接近停滞。

| 占空比 | 日志现象 |
|---:|---|
| 5% | 成功运行，瞬时RPM约198～355，仍有实际忽快忽慢 |
| 6% | RPM约77～385，多次明显掉速 |
| 8% | RPM约93～354，波动明显，运行较短 |
| 10% | RPM逐步偏低，末尾至少200 ms无霍尔边沿 |

当前结论：该现象不符合正常负载下提高占空比应增加平均转矩的规律。优先排查实验电源进入恒流导致母线电压跌落；其次检查现有换相相位在较高电流下是否产生制动转矩或把磁悬浮转子拉偏，以及叶轮/转子是否发生接触。暂时恢复5%测试值，不继续提高占空比，不加入PI。

下一项测试要求同时记录每档运行时的电源电流和电源端母线电压，特别观察掉速瞬间是否亮起CC/限流指示。若掉速时母线电压下降或进入CC，先解决供电限流；若12 V稳定且没有限流，但占空比越高越容易停，则进行换相相位/磁拉偏诊断，不用速度闭环掩盖问题。

### `reference_code`移植评估

已阅读STM32F103参考工程的主控制链路。该工程使用`HALL`、速度环模式，并采用与当前板相同类型的`H_PWM_L_ON`功率方式：一相高桥PWM、一相低桥常导通、第三相悬空。参考工程六个功率状态`Q15/Q16/Q26/Q24/Q34/Q35`可分别映射到当前的`UH+VL/UH+WL/VH+WL/VH+UL/WH+UL/WH+VL`，因此控制思路具备移植基础。

参考工程的完整思路为：18 kHz TIM1固定周期控制任务；静态定位；变步长开环六步强拖；实际Hall与期望Hall连续匹配后切入Hall闭环换相；速度滤波和PI；500 ms无Hall变化堵转关断；母线电压和相电流保护。该结构对当前磁悬浮泵的启动和闭环设计有直接参考价值。

不能直接照搬的部分：STM32F103寄存器和外设代码；参考Hall编码位序及电平；72 MHz/18 kHz计数值；4极参数（当前电机为8极）；电流和母线ADC换算；PI参数；以及30%定位、35%强拖、最高85%输出等占空比。尤其当前板尚未完成电流采样和硬件故障输入验证，不能直接使用参考工程的高占空比启动参数。

还需注意：当前参考目录配置为`TEST_MANUELL 1`，按现有宏会进入静态开关测试而不是正常闭环；定位+强拖状态机看起来包含后续修改。移植前应确认用户所说的“另一块板验证通过”具体对应哪个版本、测试模式和实际参数。

建议按以下阶段移植，而不是一次性搬入全部代码：

1. 保留当前已验证的G431安全功率输出层和Hall映射；
2. 移植参考工程的固定周期状态机框架与状态日志，初期不启用PI；
3. 先做低占空比、短时间的定位/开环单步实验，实测可跟随的步长和磁悬浮状态；
4. 确认强拖到Hall闭环的同步判据后，再加入启动状态机；
5. 改善机械圈/多边沿测速后，最后移植带限幅和抗积分饱和的速度PI；
6. 母线和电流采样标定完成后，再启用电流限制及完整保护。

### G431移植第一步：固定周期基础状态机

开始移植参考工程的控制框架，但不移植其高占空比启动参数。本阶段只加入`STOP / HALL_RUN / FAULT`三个明确状态，并使用`HAL_GetTick()`形成1 ms控制任务；现有Hall边沿中断换相、5%占空比、500 ms堵转超时和200 ms RTT输出保持不变。未加入定位、开环强拖、速度PI或ADC保护。

同时删除`main.c`中初始化后无条件点亮PC6状态灯的代码。上电状态应为全桥关闭、状态灯熄灭；进入`HALL_RUN`后点亮；停止或故障后熄灭。

本阶段验收标准：上电不驱动且灯灭；按键后日志显示`RUN duty=5%`且换相行为不比原基线退化；按键停止后立即全关；堵转或Hall异常进入`FAULT`并保持关断；再次按键允许从故障状态重新尝试启动。

### 固定周期基础状态机板上验收

完成三次5%占空比启停测试，三次均成功进入`HALL_RUN`，Hall边沿计数分别持续增长，并均由按键正常输出`STOP`。日志中没有`INV`、`JUMP`、Hall超时或意外FAULT，说明1 ms基础状态机没有破坏原有Hall换相行为，本阶段通过。

三次启动阶段均可看到RPM由低值上升。第三次启动首条状态为`RPM=0`，原因是每次启动会清空测速状态，在获得第二个合法Hall边沿前无法计算周期，属于正常现象。稳态RPM仍约在239～418 rpm之间波动，肉眼已确认存在真实转速不稳；该问题在状态机移植前已经存在，不判为本轮回归。

## 下一步计划

### G431移植第二步：受限单步诊断

在基础状态机提交`8be63bd`之后，加入由`MOTOR_DIAGNOSTIC_MODE`控制的单步诊断模式。当前宏设为1，正常Hall连续运行暂时禁用。每按一次PC10，只以5%占空比施加一个功率状态50 ms，随后自动全关并熄灭状态灯；六次按键依次测试参考工程强拖顺序`VH+WL -> VH+UL -> WH+UL -> WH+VL -> UH+VL -> UH+WL`，然后循环。

每次输出格式为`DIAG S=n H=起始->结束 dN=边沿增量`。本阶段只判断每个固定状态是否造成切向动作、Hall变化、抖动或异常径向偏移，不进行自动连续强拖。若出现明显摩擦、剧烈振动、限流或异常位移，应立即断电。完成六步后记录每一步的日志和肉眼观察，再决定是否以及如何组合为开环慢速序列。

### 单步诊断结果分析（5%～20%，50 ms）

完成5%、6%、8%、10%、20%固定50 ms单步脉冲测试。所有六个功率状态均至少在部分初始位置产生过Hall变化，未出现`000`、`111`、`INV`或`JUMP`，说明六个输出状态都能对转子施加作用，Hall采集在脉冲过程中仍正常。

总体趋势：5%多数脉冲为`dN=0`、少数为1；6%和8%主要为0～1；10%主要为0～2；20%主要为0～2、最高3。提高占空比会增加50 ms内的转子位移，但不同功率步和不同初始Hall的响应差异显著。即使20%，S3和S5等组合在某些初始位置仍多次`dN=0`，说明固定矢量存在低起动力矩位置或转子快速进入局部磁平衡位置。

不能把`H=起始->结束`直接与闭环换相表比较来判定相序。闭环表中的Hall值表示该60电角度区间应施加的转矩矢量；单步脉冲的结束Hall则是转子被一个固定磁场拉动50 ms后的瞬时位置，两者物理含义不同。此外结束采样发生在关断附近，转子仍可能依靠惯性继续移动。

本轮日志尚缺少每步的肉眼切向方向、抖动、径向偏移/摩擦以及电源CC状态，因此暂不能确认参考强拖顺序对磁悬浮状态是否安全。20%已超过保存基线的10%软件安全上限，不再继续提高或延长20%脉冲。

建议下一步不要直接进入完整自动启动，而先在最大10%范围内做一段可立即中止的低速开环序列验证：沿参考顺序循环六步，初始步长采用参考工程量级约130～150 ms，但先只执行一圈并自动全关，RTT逐步记录命令步、起止Hall和边沿数。是否采用10%以及具体步长，需结合用户本轮观察到的实际方向、振动、摩擦和CC状态共同确认后再写代码。

用户补充肉眼观察：单脉冲以切向移动为主；`dN>0`时运动方向基本一致；占空比越大径向晃动越严重，10%和20%振动明显增加；实验电源没有进入CC模式。

据此修正下一步参数：供电限流不是当前主要约束，较高占空比带来的径向磁力/悬浮扰动更值得警惕。连续六步验证从5%开始，不采用10%；每步150 ms，只执行一个六步电气圈后自动全关。成功判据是叶轮沿单一切向方向逐步跟随、Hall总体沿合法顺序变化且没有明显径向晃动；若主要表现为来回摆动、某一步明显撞击/摩擦、径向振动加剧或方向反转，立即停止，不缩短步长也不增加占空比。

已将诊断代码改为一圈连续序列模式：每按一次PC10，以5%占空比按参考顺序连续执行六步，每步150 ms，总计约900 ms，然后自动全关并输出`DIAG sequence done; outputs off`。序列运行中再次按键可立即中止。测试后留下的20%占空比和30%软件上限已恢复为5%和10%。

### 一圈连续六步结果（5%～10%，150 ms/步）

分别在5%、6%、8%、10%下各执行三次一圈六步序列，所有序列均完成并自动关断，没有非法Hall或故障。各命令步反复呈现相近的结束Hall吸引位置：S1多落在`100/101`，S2多落在`101/001`，S3多落在`001/011`，S4多落在`011/010`，S5多落在`010`，S6多落在`100/110`。结合肉眼观察的切向方向基本一致，说明参考工程六步顺序在当前相序上具有正确的定向拉动作用。

但当前`dN`只是Hall边沿总数，不区分正转和反转。固定同一个磁场150 ms期间出现`dN=3～6`，不应解释为转子持续向前越过3～6个区间；更可能包括转子越过磁平衡点、回摆、再次穿越Hall边界，以及换步瞬间的惯性运动。S4在多个占空比和多次测试中经常`dN=0`，也说明转子在进入该步时常已接近该固定矢量的平衡位置。

提高占空比没有表现出单调改善：10%仍出现S1或S4的`dN=0`，而此前已观察到占空比越大径向晃动越严重。因此下一步不继续提高占空比，也不根据`dN`直接缩短步长进入加速。应先让诊断统计区分正向边沿、反向边沿和净位移，并逐步记录Hall序列；确认一圈内反向回摆占比后，再选择5%下的下一档步长。

已升级诊断方向统计，不改变5%、150 ms/步及六步功率动作。Hall层按实测正向序列`001 -> 011 -> 010 -> 110 -> 100 -> 101 -> 001`累计正向`F`，逆序累计反向`R`，非法或非相邻变化累计`J`。每步输出改为`DIAG S=n H=起始->结束 F=x R=y J=z NET=...`，其中`NET=F-R`。下一轮仍执行三次一圈序列，用于判断150 ms固定矢量下的回摆程度。

### 方向统计结果（5%，150 ms/步）

完成六次一圈序列，共36个命令步。汇总得到正向边沿约37个、反向边沿2个、非法/非相邻跳变0个，整批净正向位移约35个Hall区间。绝大多数产生位移的步骤均为纯正向，说明参考六步顺序与当前电机/相序匹配，150 ms固定矢量下不存在大量往返回摆。

两处反向分别表现为一次S5的`F=1,R=1,NET=0`和一次S1的`F=0,R=1,NET=-1`，可能来自步切换或序列开始时转子尚未完全静止。S1多次`NET=0`，S3/S4也偶有0，但后续步骤仍能恢复正向位移，因此开环同步不能要求每个命令步都产生Hall边沿；应以一段窗口内的累计净正向位移和反向边沿上限作为判据。

下一档建议仍保持5%，将每步时间从150 ms缩短到120 ms，仍只执行一圈并自动全关，重复六次。验收判据：`J=0`；总`F`明显大于总`R`；多数序列净位移为正；肉眼没有比150 ms更严重的径向晃动、摩擦或反向。若通过，再依次评估100 ms，而不提高占空比。

代码已切换到5%、120 ms/步的一圈诊断版本，方向统计和自动全关保持不变。启动提示同步显示实际占空比和步长，等待板上测试。
